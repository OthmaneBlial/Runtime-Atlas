# Code of Conduct

Runtime Atlas welcomes contributors with different backgrounds and levels of experience. Be respectful, specific, and constructive. Debate ideas and evidence without personal attacks. Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate disruption are not accepted in project spaces.

Project maintainers may edit or remove comments, commits, issues, and other contributions that violate these expectations, and may temporarily or permanently restrict participation. Enforcement decisions should protect affected people and avoid publishing private information.

Report conduct concerns privately to the repository owner through their GitHub profile. Include only the context needed to assess the incident. Good-faith reports will be handled as confidentially and promptly as practical.
